# Behavioral competence does not entail understanding

Searle's Chinese Room argument demonstrates that a system can produce perfectly appropriate outputs in a language without understanding that language. The room's occupant follows syntactic rules to manipulate symbols but has no semantic comprehension. Similarly, an LLM manipulates tokens according to learned statistical patterns without any grasp of meaning. Functional output is necessary but not sufficient for understanding.
